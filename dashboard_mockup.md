## ข้อมูลที่ต้องการ (จาก DB)

### Per-truck dashboard query

```sql
-- 1. ข้อมูลรถ + ช่วง
SELECT t.plate, t.driver_name, t.fuel_route
FROM thira.trucks t
WHERE t.plate = '72-2420';

-- 2. เที่ยวที่วิ่ง (จาก ants.containers + thira.prices)
SELECT
  c.date_in,
  c.factory,
  c.invoice_no,
  c.container_no,
  p.fee_driver,
  CASE t.fuel_route WHEN 1 THEN p.fuel_liters_route_1 ELSE p.fuel_liters_route_2 END AS liters_target,
  -- ราคา revenue ดึงจาก freight_price_sets ตาม factory (หรือ destination_code → factory_name)
  (...)::numeric AS revenue
FROM ants.containers c
LEFT JOIN thira.prices p ON ...
LEFT JOIN thira.trucks t ON c.truck_plate = t.plate
WHERE c.truck_plate = '72-2420'
  AND date_part('year', c.date_in) = 2026
  AND date_part('month', c.date_in) = 5
  AND CASE WHEN date_part('day', c.date_in) >= 16 THEN 2 ELSE 1 END = 2  -- half = 2
ORDER BY c.date_in;

-- 3. รายจ่ายช่วงนี้
SELECT category, COUNT(*), SUM(liters), SUM(amount)
FROM thira.outcomes
WHERE truck_plate = '72-2420'
  AND date_part('year', date) = 2026
  AND date_part('month', date) = 5
  AND CASE WHEN date_part('day', date) >= 16 THEN 2 ELSE 1 END = 2
GROUP BY category;

-- 4. รายรับช่วงนี้
SELECT date, amount_gross, amount_net, note
FROM thira.incomes
WHERE truck_plate = '72-2420'
  AND date BETWEEN '2026-05-16' AND '2026-05-31';
```

ผมจะสร้าง view `thira.dashboard_truck_period` ที่รวมทุกอย่างต่อรถต่อครึ่งเดือน

## เลือกรูปแบบ Delivery

### Option A: Web app (HTML + Supabase JS — แบบเดียวกับ FREIGHT_CALC)
- ✅ Live data realtime จาก Supabase
- ✅ Deploy ฟรีบน GitHub Pages
- ✅ เปิดบนมือถือ + คอมได้
- ⏱️ ใช้เวลา 1-2 วันทำ

### Option B: Supabase Studio (no extra code)
- ✅ ไม่ต้องเขียนโค้ดเลย
- ❌ ต้อง login Supabase ดู
- ❌ UI ไม่ custom — เห็นเป็น table flat

### Option C: Excel-style sheet ที่ refresh จาก Supabase
- ✅ คุ้นเคย
- ❌ ต้อง refresh manual

### Option D: PDF/Print-friendly report (PDF รายเดือน)
- ✅ พิมพ์ archive ได้
- ✅ ส่ง email ได้
- ❌ ไม่ interactive
